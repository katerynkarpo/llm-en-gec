GEC API

Offline documentation for the minimal-edit English correction service.

Endpoints

POST/api/correct
Correct text with a selected model, paper recipe, and few-shot mode.
GET/api/options
List server-approved models, A1–A6.4 recipes, and few-shot limits.
GET/api/example?count=2
Sample the requested number of erroneous sentences dynamically from BEA train.
GET/api/health
Check whether the GEC application is running.

Correction example

curl -X POST http://127.0.0.1:8080/api/correct \
  -H 'Content-Type: application/json' \
  -d '{
    "text": "She do not likes it. Her friends likes it too.",
    "model": "gpt-4.1-mini",
    "recipe": "a6_4",
    "batch_size": 2,
    "temperature": 0,
    "few_shot_mode": "paper"
  }'

Few-shot modes

paper uses the recipe’s published default. seeded samples deterministically using few_shot_n and few_shot_seed. custom accepts up to eight source/reference pairs. none runs zero-shot.

Sentence batching

batch_size controls how many independently corrected sentences are sent in each model request. The text must contain at least that many sentences; a final partial batch is allowed.

Temperature

Temperature limits are model-specific and are returned by /api/options. Omit temperature to use the profile default. For reproducible GEC runs, use 0. GPT-5.4 requests with reasoning effort enabled must omit temperature.
